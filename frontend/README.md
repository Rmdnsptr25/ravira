# RAVIRA Frontend

Frontend awal RAVIRA menggunakan React, Vite, TypeScript, React Router, dan CSS biasa.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Environment

```bash
VITE_API_BASE_URL=http://localhost:4000/api/v1
```

Backend, Supabase, auth, dan signaling/liveapp belum dihubungkan pada setup awal ini.
