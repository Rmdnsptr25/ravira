Buat desain UI/UX lanjutan setelah landing page untuk website **Ravira — DS Recruitment Ecosystem**.

Ravira adalah ekosistem rekrutmen berbasis AI yang membantu kandidat menemukan pekerjaan relevan, memahami skill gap, mendapatkan rekomendasi pelatihan personal, serta mengakses peluang kerja lintas wilayah. Ravira juga membantu perusahaan mendapatkan shortlist kandidat berbasis AI dan membantu pemerintah melihat workforce analytics berbasis data.

Gunakan Bahasa Indonesia untuk seluruh teks UI.

## Gaya Desain

Gunakan style yang sama dengan landing page Ravira:

* Modern SaaS
* Profesional
* Futuristik
* Bersih dan mudah dipahami
* Warna utama dark navy, cyan, electric blue, teal, putih, dan soft gray
* Rounded card
* Soft shadow
* Dashboard modern
* Responsive desktop dan mobile
* Konsisten dengan branding Ravira

## Alur Halaman

Buat user flow yang saling terhubung seperti ini:

Landing Page:

* Tombol “Masuk” mengarah ke halaman Login
* Tombol “Mulai Sekarang” mengarah ke halaman Pilih Role / Registrasi
* Tombol “Cari Pekerjaan Sekarang” mengarah ke Registrasi Kandidat
* Tombol “Daftarkan Perusahaan” mengarah ke Registrasi Perusahaan
* Tombol “Lihat Solusi Analytics” mengarah ke Registrasi Pemerintah / Institusi

## Halaman yang Harus Dibuat

### 1. Halaman Login

Buat halaman login dengan layout modern.

Isi halaman:

* Logo Ravira
* Judul: “Masuk ke Ravira”
* Subjudul: “Lanjutkan perjalanan karier, rekrutmen, atau analitik tenaga kerja Anda.”
* Input email
* Input password
* Checkbox “Ingat saya”
* Link “Lupa password?”
* Tombol utama: “Masuk”
* Tombol login Google
* Tombol login LinkedIn
* Link bawah: “Belum punya akun? Daftar sekarang”

Tambahkan pilihan role login:

* Kandidat
* Perusahaan
* Pemerintah / Institusi

Setelah login:

* Kandidat masuk ke Dashboard Kandidat
* Recruiter masuk ke Dashboard Perusahaan
* Pemerintah / Institusi masuk ke Dashboard Analytics

### 2. Halaman Pilih Role Registrasi

Judul:

“Pilih jenis akun yang sesuai agar Ravira dapat memberikan pengalaman terbaik.”

Tampilkan 3 kartu pilihan:

1. Kandidat
   Deskripsi: “Cari pekerjaan, analisis skill gap, dan dapatkan rekomendasi pelatihan personal.”
   Tombol: “Daftar sebagai Kandidat”

2. Perusahaan / Recruiter
   Deskripsi: “Temukan kandidat terbaik lebih cepat dengan shortlist berbasis AI.”
   Tombol: “Daftarkan Perusahaan”

3. Pemerintah / Institusi
   Deskripsi: “Pantau tren tenaga kerja, kebutuhan skill, dan data workforce regional.”
