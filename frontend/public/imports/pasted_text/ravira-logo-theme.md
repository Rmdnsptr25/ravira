## 4. Tambahkan Light Mode dan Dark Mode

Tambahkan dua mode tampilan:

* Light Mode
* Dark Mode

Light mode tetap mempertahankan desain yang sudah ada.

Dark mode harus mengikuti identitas Ravira:

* Background utama: dark navy
* Card: navy lebih terang
* Border: slate transparan
* Text utama: putih
* Text sekunder: slate terang
* CTA utama: biru/cyan Ravira
* Hover: biru transparan
* Active menu: cyan/electric blue
* Input: dark card dengan border slate
* Modal: dark navy card
* Toast: dark card dengan highlight sesuai status

Jangan membuat warna terlalu ramai.

## 5. Toggle Tema

* Icon bulan untuk dark mode
* Toggle bisa diklik

* Letakkan di navbar publik dan header dashboard
